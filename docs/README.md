# Project website

This folder is the project's one-page website, published with GitHub Pages at
https://fifteenk.github.io/Outlook-Company-Signature/

**It isn't part of the add-in.** You don't need it to deploy the add-in, and you can delete it from your fork.

- `index.html`: the page itself
- `assets/`: copies of the images the page uses, because GitHub Pages only serves files inside this folder
- `.nojekyll`: tells GitHub Pages to serve the files as they are, without running them through Jekyll

GitHub Pages is set to deploy from the `main` branch, `/docs` folder.
